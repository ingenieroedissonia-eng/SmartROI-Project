## Project Overview

SmartROI v2.0 allows importers and traders to evaluate the viability of a product in seconds. It calculates total costs, import taxes, margins, and ROI, then delivers an automatic investment verdict based on configurable thresholds.

Built as part of the M.A.I.I.E. ecosystem — architecture-first, business-impact-driven.

---

## Tech Stack

- Python 3.10+
- Streamlit
- Pandas

---

## Key Features

### Financial Simulation
- Total investment cost calculation
- Import tax computation (15% tariff)
- Projected sales revenue
- Net profit and ROI

### Decision Engine
Automatic investment classification:
- Elite Opportunity: ROI >= 40%
- Viable Business: ROI >= 15%
- High Risk: ROI < 15%

### Data Visualization
- Real-time financial KPIs
- Investment vs. Profit comparative charts
- Detailed metrics table
- Visual risk alerts
